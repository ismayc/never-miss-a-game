Two steps, in the order the agent uses them. Step 1 is your preferences.json: open it, tick your teams, turn the dial, and Save writes the same file back. Step 2 reads this week's schedules, the same read the agent gets, and shows which of the week's games are yours.

Step 1 Set up your preferences

The agent reads preferences.json and nothing else about you. Open that file (or try the example), tick your teams and turn the dial, and Save writes the same file back. The JSON on the right is exactly what gets saved.

This browser cannot write a file in place (Chrome and Edge can). You can still open your preferences.json, edit it here, and Download the result; put that file over preferences.json in your checkout.

    Step 2 Read this week's schedules

    The agent's whole data layer is one local script, node read-schedules.mjs, which reads ten schedule repos and your preferences and prints the week. GitHub runs that same script from this repo a few times a day and publishes what it prints; this button fetches it, and the box under it checks the teams you ticked in step 1 against that week. Nothing runs on your computer.
